# Python Calculator

Ein einfacher Taschenrechner mit Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Language

Python

## How to Run

1. Install Python from python.org
2. Clone this repository
3. Run the program:

```bash
python calculator.py
```

## Example Output

```text
=== Calculator ===

Gib die erste Zahl ein: 10
Wähle (+ - * /): *
Gib die zweite Zahl ein: 5

Ergebnis: 50
```
